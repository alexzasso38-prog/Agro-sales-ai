# Agro Sales AI — presentazione GitHub Pages

Frontend compilato dal commit 7286e86074e4d3e0d8a83c0d5ea69ba0a785aed8, senza modifiche al codice originale.

Questa presentazione usa esclusivamente dati fittizi generati in un database temporaneo e cancellato dopo l’esportazione. Non contiene credenziali, token di accesso validi, database o configurazioni private. L’accesso demo è una simulazione locale del browser, non un’autenticazione.

È possibile navigare le schermate e consultare i dati. Salvataggi, campagne, invii, chiamate e worker sono disabilitati; le azioni restituiscono un messaggio esplicito. Le metriche rappresentano uno snapshot demo, non attività in tempo reale.

Attivazione: repository → Settings → Pages → Deploy from a branch → gh-pages → / (root) → Save.
Il repository resta privato: Pages su repository privati richiede un piano GitHub che lo supporti. Il sito pubblicato può essere pubblico anche se il repository è privato.
